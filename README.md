# jp-trip

A simple web app to plan your Japan trip itinerary.

## Features

- Add destinations with travel dates
- Itinerary sorted by date
- Persists data in browser local storage

## Usage

Open `index.html` in any modern web browser — no build step required.

1. Enter a destination (e.g. Tokyo, Kyoto, Osaka)
2. Pick a date
3. Click **Add** to add it to your itinerary
4. Click **✕** next to any destination to remove it
